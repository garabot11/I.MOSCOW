# Видео

Записано 20.10.2026 скриптом `docker/record_demo.sh` на образе поставки `metro-lidar:gpu-dev`
(`a0e1e7e33476`): всё запущено так же, как это сделает оператор (`./run.sh --data …`, затем
`./run.sh play …` с переключением записей без перезапуска). Детектор и RViz работают на GPU (RTX 5060 Laptop,
RViz через PRIME), записи играются со скоростью 1.0 (реальное время). В кадре — окно RViz, вверху подпись
сцены и последние строки консоли статуса (кадр, статус, расстояние, «checked to», время обработки, ближайший
объект).

Полное демо одним файлом (3 мин 55 с, 1920 × 1080) — `metro_demo_v3.mp4` в
[релизе v3](https://github.com/garabot11/I.MOSCOW/releases/tag/v3). Время обработки в строках статуса
(60–100 мс на отредактированных облаках) выше, чем в замерах без графики: RViz и запись экрана работают на той же
машине.

Перезаписать: `solution/docker/record_demo.sh --data <датасет> --out <папка>` (нужны рабочий стол X11 и
`ffmpeg`; окно RViz записывается целиком, поверх него ничего не открывать около 4 минут).
